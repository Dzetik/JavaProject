3. Что важно учесть
Изменять состояние может только участник игры.
Завершённую игру изменять нельзя.
Событие отправляется только после успешного завершения транзакции.
SimpMessagingTemplate остаётся исключительно в GameWebSocketService.

Для одновременных запросов двух игроков также потребуется защита от потери обновлений.
Здесь можно использовать JPA @Version, но тогда его лучше отделить от тестового игрового счётчика.
